# XMPP File Storage & Gallery Bot

Этот бот предназначен для хранения и обмена файлами через протокол XMPP (Jabber). Он поддерживает современные методы передачи файлов, управление через чат и предоставляет веб-интерфейс (галерею) для просмотра загруженного контента.

## Основные возможности

- **Передача файлов**:
  - **Jingle (XEP-0234)**: Современный стандарт с поддержкой SOCKS5 Bytestreams (XEP-0065) и In-Band Bytestreams (IBB).
  - **Stream Initiation (SI, XEP-0096)**: Совместимость со старыми клиентами.
  - **Out-of-Band Data (XEP-0066)**: Загрузка файлов по прямым ссылкам из чата.
  - **Bits of Binary (BoB, XEP-0231)**: Получение и отображение эскизов (thumbnails) при передаче.
- **Управление файлами**: Полноценный набор команд для работы с директориями и файлами (ls, mkdir, mv, rm).
- **Фильтрация**: Поддержка фильтрации вывода `ls` по номерам или шаблонам (например, `lss *.jpg`).
- **Веб-галерея**: Возможность включения PHP-галереи для удобного просмотра фото и видео через браузер.
- **Безопасность**:
  - Разграничение доступа через белый и чёрный списки (JID или домены).
  - Дисковые квоты для пользователей.
  - Защита от загрузки потенциально опасных файлов (PHP-скрипты, .htaccess).
  - SSRF-защита при загрузке по ссылкам.

## Установка и запуск

### Требования
- Docker и Docker Compose
- XMPP аккаунт для бота

### Запуск через Docker
1. Скопируйте `env.example` в `.env` и настройте параметры подключения:
   ```bash
   cp env.example .env
   ```
2. Отредактируйте `.env`, указав `XMPP_JID`, `XMPP_PASSWORD` и `BASE_URL`.
3. Запустите контейнеры:
   ```bash
   docker-compose up -d
   ```

## Конфигурация (.env)

| Переменная | Описание |
|------------|----------|
| `XMPP_JID` | JID бота (например, bot@example.com) |
| `XMPP_PASSWORD` | Пароль от аккаунта бота |
| `ADMIN_JID` | JID администратора (полный доступ к командам управления) |
| `BASE_URL` | Публичный URL для доступа к файлам через веб |
| `QUOTA_GB` | Лимит дискового пространства на одного пользователя (в ГБ) |
| `MAX_DIR_DEPTH` | Максимальная глубина вложенности папок (по умолчанию 2) |

## Команды бота

### Пользовательские команды
- `ls [фильтр]` — список файлов. Фильтр может быть номером или шаблоном (например, `ls *.png`).
- `lss [фильтр]` — список файлов с указанием размера.
- `lsl [фильтр]` — подробный список (размер, дата загрузки).
- `mkdir <название>` — создать новую папку.
- `rmdir <номер|путь>` — удалить пустую папку.
- `mv <номер|путь> <цель>` — переместить или переименовать файл/папку.
- `rm <номер>[,<номер>...]` — удалить файлы по номерам. Команда `rm * confirm` удаляет всё содержимое.
- `link <номер>[,<номер>...]` — получить прямые ссылки на файлы. `link *` — ссылки на все файлы.
- `priv` / `pub` — сделать архив приватным (скрыть список файлов в вебе) или публичным.
- `album` — включить режим фотогалереи.
- `ping` — проверка связи.
- `help` или `?` — справка.

### Админ-команды
- `add <jid|domain|*>` — добавить в белый список (доступ всем: `add *`).
- `del <jid|domain|*>` — удалить из белого списка.
- `block <jid|domain>` — добавить в чёрный список.
- `unblock <jid|domain>` — убрать из чёрного списка.
- `list` — показать текущие списки доступа.

## Структура проекта

- `bot.py` — основная логика бота и инициализация.
- `plugins/` — модульная архитектура бота:
  - `commands.py` — обработка текстовых команд.
  - `file_transfer.py` — реализация протоколов передачи файлов (Jingle, SI, SOCKS5).
  - `presence.py` — управление статусом и Service Discovery.
- `utils.py` — вспомогательные функции (безопасные пути, форматирование размера и др.).
- `database.py` — работа с SQLite (списки доступа, привязка папок).
- `nginx/` — конфигурация веб-сервера.
