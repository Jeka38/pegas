# OBBFastBot

XMPP-бот для быстрого обмена файлами и организации личного файлового архива. Бот позволяет загружать файлы через XMPP (Jingle, SOCKS5, IBB) или по прямым ссылкам, управлять ими через команды чата и просматривать через веб-интерфейс.

## Основные возможности

- **Современная передача файлов**: Поддержка Jingle File Transfer (XEP-0234), SOCKS5 Bytestreams (XEP-0065) и WebRTC ICE-UDP (XEP-0176) для обхода NAT.
- **Управление архивом**: Команды для создания директорий, перемещения, переименования и удаления файлов.
- **Веб-галерея**: Автоматическая генерация `index.php` для удобного просмотра изображений и файлов через браузер.
- **Гибкий доступ**: Белый и черный списки пользователей, управление доступом на лету.
- **Квотирование**: Ограничение дискового пространства для каждого пользователя.
- **Загрузка по ссылкам**: Бот автоматически скачивает файлы, если прислать ему HTTP-ссылку.

## Команды пользователя

| Команда | Описание |
| :--- | :--- |
| `ls [фильтр]` | Список файлов и папок. Фильтр: номер, путь или маска (напр. `*.mp3`) |
| `lss [фильтр]` | Список файлов с указанием их размера. |
| `lsl [фильтр]` | Подробный список (размер, дата загрузки). |
| `mkdir <путь>` | Создать новую директорию. |
| `rmdir <номер\|путь>` | Удалить пустую директорию. |
| `mv <откуда> <куда>` | Переместить или переименовать файл/папку (можно использовать номера). |
| `rm <номер\|*>` | Удалить файл(ы) по номеру. `rm * confirm` — удалить всё. |
| `link <номер\|*>` | Получить прямую HTTP-ссылку на файл(ы). |
| `priv` | Сделать архив приватным (создает `index.html`, скрывая список файлов). |
| `pub` | Сделать архив публичным (удаляет `index.html`). |
| `album` | Включить режим фотогалереи (использует `index.php`). |
| `ping` | Проверить, в сети ли бот. |
| `help` | Показать справку по командам. |

## Команды администратора

- `add <jid|domain|*>` — добавить в белый список (используйте `*` для общего доступа).
- `del <jid|domain|*>` — удалить из белого списка.
- `block <jid|domain>` — добавить в черный список.
- `unblock <jid|domain>` — удалить из черного списка.
- `list` — показать текущие списки доступа.

## Установка и запуск

### Требования
- Python 3.9+
- Доступ к XMPP-серверу
- Docker и docker-compose (рекомендуется)

### Запуск через Docker
1. Склонируйте репозиторий.
2. Скопируйте `env.example` в `.env` и заполните необходимые параметры:
   ```bash
   cp env.example .env
   ```
3. Соберите и запустите контейнеры:
   ```bash
   docker-compose up -d
   ```

## Конфигурация

Параметры в `.env`:
- `XMPP_JID`: JID бота (например, `bot@example.com`).
- `XMPP_PASSWORD`: Пароль от учетной записи.
- `ADMIN_JID`: JID администратора для управления доступом.
- `BASE_URL`: Базовый URL, по которому будут доступны файлы (напр. `https://files.example.com`).
- `QUOTA_GB`: Лимит места на одного пользователя в ГБ (по умолчанию 15).
- `MAX_DIR_DEPTH`: Максимальная вложенность папок (по умолчанию 2).
- `SOCKS5_PORT`: Порт для входящих SOCKS5 соединений (по умолчанию 1080).
- `SOCKS5_IP`: Публичный IP или домен для SOCKS5 кандидатов.
- `DB_PATH`: Путь к файлу базы данных SQLite.
